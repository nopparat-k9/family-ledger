ค่าเริ่มต้นเหล่านี้มาจากรายการที่บันทึกซ้ำทุกเดือนของคุณ (เช่น เงินฝากธนาคารพ่อ/แม่, ผ่อนรถ, ค่าเช่าบ้าน) ติ๊กถูกเพื่อเลือกว่าจะบันทึกรายการไหนบ้าง แก้ไขจำนวนเงิน/บันทึกช่วยจำได้ก่อนกดบันทึก และกด "บันทึกการเปลี่ยนแปลงเป็นค่า Default ใหม่" หากต้องการให้ค่าที่แก้ไขนี้เป็นค่าเริ่มต้นของเดือนถัดไปด้วย

เลือกบัญชีเดบิต/เครดิตและจำนวนเงิน เพื่อดูตัวอย่างผลลัพธ์

ข้อมูลบัญชี (SQLite)

✓ ตอนนี้แอปจะบันทึกฐานข้อมูลอัตโนมัติไว้ในเบราว์เซอร์นี้ (IndexedDB) ทุกครั้งที่มีการเปลี่ยนแปลง — ไม่ต้องนำเข้าไฟล์ใหม่ทุกครั้งที่เปิดแอปอีกต่อไป ตราบใดที่เปิดจากเครื่อง/เบราว์เซอร์เดียวกัน (ล้างประวัติเบราว์เซอร์ หรือใช้โหมดไม่ระบุตัวตน/เบราว์เซอร์อื่น จะทำให้ข้อมูลนี้หายไป)
คลิกเพื่อนำเข้าไฟล์ฐานข้อมูล (.db) — ใช้ตอนเปิดเครื่อง/เบราว์เซอร์ใหม่ครั้งแรก เช่น accounting.db ที่แปลงจากระบบ Access เดิม

แนะนำให้กด "ดาวน์โหลดฐานข้อมูล" เป็นระยะเพื่อเก็บสำรองไว้นอกเบราว์เซอร์ — เผื่อกรณีล้างข้อมูลเบราว์เซอร์โดยไม่ตั้งใจ หรือต้องการย้ายไปใช้งานที่เครื่อง/เบราว์เซอร์อื่น (ดาวน์โหลดจากเครื่องนี้ แล้วนำเข้าที่เครื่องใหม่)

ซิงค์ข้ามอุปกรณ์ผ่าน Google Drive

ซิงค์ฐานข้อมูลอัตโนมัติ (ทุก ~12 วินาที) ระหว่างอุปกรณ์ผ่าน Google Drive ของคุณเอง — ใช้สิทธิ์แบบจำกัดเฉพาะไฟล์ที่แอปนี้สร้าง/เปิด/ถูกแชร์มาให้เท่านั้น (ไม่แตะไฟล์อื่นใน Drive) ต้องเปิดแอปนี้ผ่านลิงก์เว็บ (https://) ไม่ใช่ไฟล์ในเครื่อง และตั้งค่า Google Cloud project ก่อน 1 ครั้ง (ดูขั้นตอนในไฟล์ GOOGLE_DRIVE_SYNC_SETUP.md ที่แนบมา)

แจ้งเตือนผ่าน LINE

LINE Notify (ระบบโทเคนเดิม) ถูกยกเลิกไปแล้วตั้งแต่ 31 มี.ค. 2568 โดย LINE ให้ใช้ LINE Messaging API แทน ซึ่งต้องมีเซิร์ฟเวอร์ตัวกลางเล็กๆ ของคุณเอง (ตัวอย่างอยู่ในไฟล์ line-relay-server.js ที่แนบมาด้วย)
